BUREAU OBSCURA AUDIO FABRICATOR 1.0.0

1. Keep the complete extracted folder together.
2. Open "Bureau Obscura Audio Fabricator.exe".
3. Windows may take several minutes on first launch while the local engines
   initialize. Music generation requires a supported NVIDIA GPU; Sound mode
   uses the bundled CPU-optimized Stable Audio 3 Small SFX runtime.
4. Closing the application window stops both local engines.

Your library is stored separately at:
  %LOCALAPPDATA%\YuE Studio

No generated takes, prompts, credentials, or browser profiles are included in
this distribution.
